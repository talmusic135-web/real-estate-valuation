# העלאת ערך+ לאתר קבוע (בלי להריץ כלום במחשב)

בסוף התהליך תהיה לכם כתובת קבועה (למשל `https://erech-plus.vercel.app`) שנכנסים אליה מכל מחשב או טלפון, עם סיסמה. כל עדכון שנדחף ל-GitHub מתעדכן באתר לבד.

**מה צריך:** חשבון GitHub (כבר יש), חשבון Vercel (אירוח האתר), ומסד נתונים Neon (נפתח מתוך Vercel, בלי חשבון נפרד). כ-10 דקות.

## שלב 1 – פתיחת חשבון Vercel
1. נכנסים ל-https://vercel.com/signup
2. בוחרים **Hobby**, כותבים שם, ולוחצים **Continue with GitHub**. מאשרים את החיבור.

## שלב 2 – חיבור הקוד
1. במסך הראשי של Vercel: **Add New…** ← **Project**.
2. ברשימה מופיע `real-estate-valuation` ← לוחצים **Import**.
   אם הוא לא מופיע: לוחצים **Adjust GitHub App Permissions** ומאשרים גישה לריפו הזה.
3. פותחים את **Environment Variables** ומוסיפים:
   - Name: `APP_PASSWORD`
   - Value: סיסמה שתבחרו לכניסה למערכת (לפחות 10 תווים)
4. לוחצים **Deploy**. הבנייה לוקחת כ-2 דקות. בשלב הזה האתר עוד לא יעבוד, כי אין מסד נתונים. זה צפוי.

## שלב 3 – מסד נתונים
1. בתוך הפרויקט ב-Vercel: לשונית **Storage** ← **Create Database**.
2. בוחרים **Neon** (Serverless Postgres) ← **Continue**.
3. אזור (Region): **Frankfurt**. תוכנית: **Free**. ← **Create**.
4. במסך החיבור מסמנים את כל הסביבות (Production, Preview, Development) ← **Connect**.

## שלב 4 – הפעלה
1. לשונית **Deployments** ← בשורה העליונה לוחצים על **⋯** ← **Redeploy**.
2. בבנייה הזו המערכת יוצרת לבד את הטבלאות ומכניסה נתוני הדגמה (רק בפעם הראשונה; נתונים שתשמרו לא נמחקים בעדכונים).
3. כשמופיע **Ready**, לוחצים **Visit**. זו הכתובת שלכם. שמרו אותה במועדפים.
4. נכנסים עם הסיסמה מ-`APP_PASSWORD`.

## עלויות
| שירות | עלות |
|---|---|
| Vercel Hobby | חינם. **שימו לב:** לפי תנאי Vercel, Hobby מיועד לשימוש אישי ולא מסחרי. לשימוש שוטף של משרד תיווך צריך **Pro** (כ-20$ לחודש). אפשר להתחיל ב-Hobby לניסיון. |
| Neon Free | חינם עד 0.5GB, מספיק לעשרות אלפי עסקאות. |
| Anthropic (סיכום בשפה טבעית) | לא חובה. בלי מפתח המערכת כותבת סיכום מתבנית. עם מפתח: תשלום לפי שימוש, אגורות בודדות להערכה. |

## הגדרות נוספות (לא חובה)
ב-Vercel ← **Settings** ← **Environment Variables**, ואחרי כל שינוי **Redeploy**:
- `ANTHROPIC_API_KEY` – סיכום בשפה טבעית.
- `DEMO_DATA_ENABLED=false` – כשיהיו נתונים אמיתיים.
- החלפת `APP_PASSWORD` מנתקת את כל מי שמחובר.

## מגבלות באירוח הזה
- **PDF:** כפתור ה-PDF פותח את חלון ההדפסה של הדפדפן; בוחרים "שמירה כ-PDF". (יצירת PDF בשרת דורשת Chromium, שקיים רק בהרצה עם Docker.)
- **סיסמה אחת למשרד.** משתמשים נפרדים והרשאות – בהמשך.

## אם משהו לא עובד
- `https://<הכתובת שלכם>/api/health` מחזיר `"db":true` כשהמסד מחובר.
- אם מופיע "משהו השתבש": בדקו שעשיתם את שלב 3, ואז Redeploy.
- ב-Vercel ← Deployments ← הבנייה האחרונה ← **Build Logs** רואים מה נכשל.
