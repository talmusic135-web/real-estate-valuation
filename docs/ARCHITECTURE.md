# ארכיטקטורה

```
Next.js (App Router, TypeScript)
├── src/app/                  מסכים (Server Components) + API Routes
├── src/components/           רכיבי ממשק (טופס, טבלאות, מפה, גרפים)
└── src/lib/
    ├── domain/               סכמות Zod, מבנה הרשומה האחיד, תוויות בעברית
    ├── valuation/            מנוע ההערכה – פונקציות טהורות, ללא גישה למסד
    │   ├── similarity.ts     ציון דמיון 0–100 + סיבות
    │   └── engine.ts         סינון → חיפוש מדורג → התאמת זמן → חריגים → שקלול → אומדן, טווח, אמינות, רגישות
    ├── connectors/           מחבר לכל מקור מידע + רישום + נרמול + הגבלת קצב
    ├── ai/                   שכבת Provider למודל שפה + בקרת מספרים + סיכום תבניתי
    ├── demo/                 מחולל נתונים סינתטיים (seed קבוע)
    └── services/             תזמור: שליפה מהמקורות, שמירה, חישוב, שמירת תוצאה
PostgreSQL + Prisma
```

## זרימת הערכה

1. הטופס נשלח ל-`POST /api/valuations` ומאומת ב-Zod.
2. `runAndSave` מריץ את כל המחברים במקביל (`runConnectors`), כל אחד עם timeout ובידוד שגיאות. מקור שנכשל מסומן "שגיאה" ומופיע במגבלות הדוח; החישוב ממשיך.
3. רשומות חדשות נשמרות עם מניעת כפילויות: מפתח ייחודי (מקור + מזהה), ובנוסף זיהוי אותה עסקה משני מקורות (`crossSourceKey`).
4. המנוע מקבל את כל הרשומות בעיר ומחזיר תוצאה מלאה ומוסברת.
5. מודל השפה מקבל רק "גיליון עובדות" ומנסח סיכום. כל מספר בטקסט נבדק מול הגיליון; אם יש מספר לא מוכר – הסיכום נדחה ומוצג סיכום תבניתי.
6. ההערכה נשמרת עם: הקלט, התוצאה, גרסת האלגוריתם, המקורות והסטטוס שלהם, ועסקאות ההשוואה (כולל צילום מצב).

## החלטות עיקריות

- **שווי רק מעסקאות שהושלמו.** מודעות משמשות לניתוח מתחרים ולהמלצת מחיר מבוקש בלבד.
- **אין מקדמי התאמה שרירותיים.** מאפיינים משפיעים על משקל העסקה, לא על המחיר. מקדמים מכוילים יתווספו רק אחרי כיול מול נתונים אמיתיים (שלב 3).
- **התאמת זמן מכוילת מהנתונים** (רגרסיה של ln מחיר למ״ר על הזמן) ומופעלת רק אם מובהקת.
- **חציון משוקלל** במקום ממוצע, וזיהוי חריגים ב-MAD.
- **בלי מספיק נתונים – בלי אומדן.** מתחת ל-3 עסקאות לא מוצג אומדן.
- **הפרדת חשבונות** כבר במודל הנתונים (`accountId` בכל הערכה); `getCurrentContext` הוא נקודת ההחלפה להתחברות אמיתית.
- **PDF** מרונדר בשרת ע״י Chromium מאותו עמוד דוח, כך שהעברית וה-RTL זהים למסך. אם Chromium לא זמין – הדפסה מהדפדפן.
