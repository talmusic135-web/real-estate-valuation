# מקורות נתונים – מה מחובר ומה האפשרויות

## עסקאות שבוצעו (הבסיס לאומדן)

| מקור | מצב | הערות |
|---|---|---|
| **רשות המסים דרך GovMap** | בנוי, **כבוי כברירת מחדל**. מפעילים בלחיצה במסך "מקורות מידע" | עסקאות אמיתיות שדווחו לרשות המסים. השליפה משתמשת בנקודות הקצה הציבוריות שאתר GovMap עצמו משתמש בהן; זה **לא API רשמי ומתועד**, ולכן ההפעלה דורשת אישור שבדקתם את תנאי השימוש. המערכת שולחת עד 4 בקשות להערכה, בקצב איטי, ולא עוקפת חסימות. אם GovMap חוסם או משנה את הממשק, המקור מסומן כשגיאה וההערכה ממשיכה עם שאר המקורות. |
| אתר מידע הנדל״ן (nadlan.gov.il) | מחבר כללי בנוי, לא מחובר | לא מצאנו API ציבורי ומתועד. אם יתקבל ערוץ גישה מאושר: `GOVIL_NADLAN_ENABLED=true` + `GOVIL_NADLAN_API_URL`. |
| קובץ CSV שיוצא מהאתר הממשלתי | **פעיל** | העלאה במסך "מקורות מידע". |
| הזנה ידנית | **פעיל** | עסקאות שהמתווך מכיר. |

**הפרדה מנתוני הדגמה:** ברגע שיש בעיר אפילו עסקה אמיתית אחת, נתוני ההדגמה של אותה עיר לא נכנסים יותר לחישוב. כל עסקה מוצגת עם המקור שלה.

## מודעות (לניתוח מתחרים ולטווח מחיר מבוקש בלבד)

מחיר מבוקש לעולם אינו מוצג כמחיר מכירה. האפשרויות החוקיות:

1. **הסכם עם אתר מודעות** (יד2, מדלן וכו׳). לאתרים אלה אין API ציבורי פתוח, ותנאי השימוש שלהם אוסרים איסוף אוטומטי. המערכת **לא** גורפת אותם.
2. **ספק נתונים מורשה** שיש לו הסכם עם האתרים. המחבר מוכן: `LISTINGS_PROVIDER_URL` + `LISTINGS_PROVIDER_API_KEY`, ומחזיר רשומות במבנה האחיד (docs/DATA_IMPORT.md).
3. **קובץ או הזנה ידנית**: המתווך מעלה רשימת מודעות שאסף בעצמו (CSV), או מוסיף מודעה בודדת.

ההחלטה איזה ספק לבחור (ועלותו) היא עסקית; כשתיבחר, החיבור הוא הגדרת שני משתנים.
